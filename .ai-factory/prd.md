# ZeroSpendStreak

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
하루 지출 0원에 도전하고 연속 성공일수를 기록하며 친구와 순위를 겨루는 무지출 챌린지 스트릭 앱

## Problem
저축을 결심해도 오늘 하루 돈을 안 썼는지 스스로 체크하고 동기부여할 도구가 없어 절약 습관이 작심삼일로 끝남

## Target Users
저축/절약을 목표로 삼는 20-30대 사회초년생, 앱테크에 익숙한 유저

## Core Features
1. 하루 무지출 성공 체크인
2. 연속 성공일수(스트릭) 시각화
3. 친구 초대 및 랭킹 경쟁
4. 주간/월간 무지출 달성률 통계
5. 스트릭 실패 시 리워드 광고로 1회 복구권 획득
6. 마일스톤 뱃지 수집

## Monetization
- Model: ads
- Estimated MRR: $321
- Reasoning: 매일 체크인하는 습관형 구조로 배너 노출이 자연스럽고, 스트릭이 끊겼을 때 '광고 시청 후 복구' 리워드 게이팅이 이탈 방지와 수익을 동시에 확보
