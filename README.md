# ZeroSpendStreak

앱인토스 (Vite + React + TDS) 하루 지출 0원에 도전하고 연속 성공일수를 기록하며 친구와 순위를 겨루는 무지출 챌린지 스트릭 앱 저축을 결심해도 오늘 하루 돈을 안 썼는지 스스로 체크하고 동기부여할 도구가 없어 절약 습관이 작심삼일로 끝남

## Tech Stack

- React 18.0.0
- TypeScript
- Vitest
